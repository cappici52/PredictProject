# Lucky Pixel

เว็บสถิติหวยส่วนตัว ภาษาไทย สไตล์ Pixel Art เปิดผ่านเบราว์เซอร์ ไม่ต้องสมัครสมาชิกหรือใช้ API key

## เปิดใช้งาน

ต้องมี Node.js 20.19+ หรือ 22.12+ และ npm

```powershell
npm install
npm run dev
```

เปิด http://127.0.0.1:5173 เซิร์ฟเวอร์ผูกกับเครื่องนี้เท่านั้น ไม่มีรหัสผ่านเพราะใช้ส่วนตัว

```powershell
npm run build
npm start
npm test
```

## ฟีเจอร์

- ตาราง 00–99 ตามรางวัลเลขท้าย 2 ตัวจริง เลือกย้อนหลังได้ทุกจำนวนปีตั้งแต่ 1 ถึง 20 ปี สีเข้ม = ออกบ่อย แตะดูทุกวันที่เคยออก
- ข้อมูลจริง 496 งวดในคลังตั้งต้น (2549–2569) ระบุแหล่งรายงวด เก็บเลขศูนย์นำหน้า และดาวน์โหลด CSV ได้
- อัปเดต GLO อัตโนมัติทุก 2 นาทีขณะเซิร์ฟเวอร์เปิด เก็บแคชใน data/cache.json และดึงงวดที่ขาดหลังปิดเครื่องกลับมา หากเชื่อมต่อไม่ได้ยังใช้ข้อมูลเดิมได้พร้อมข้อความสถานะ
- กรอกผลและวันที่งวดก่อน คำนวณ 2 ตัว 2 ชุด และ 6 ตัว 1 ชุดแบบไม่มีการสุ่ม เปลี่ยนอินพุตหรือช่วงปีแล้วล้างผลเก่าป้องกันความสับสน
- เพิ่ม Top 10 ทั้งเลข 2 ตัวและเลข 6 ตัว เรียงตามน้ำหนักแบบจำลอง พร้อมกดดูเหตุผลรายชุด คะแนนเท่ากันเรียงเลขน้อยก่อน
- ช่วงที่มีข้อมูลน้อยกว่า 60 งวด เช่น 1–2 ปี เลข 2 ตัวใช้ความถี่สะสม ส่วน 6 ตัวใช้ความถี่รายหลักปรับเรียบ 10 โดยไม่อ้างว่าได้เลือกสูตรที่ดีที่สุดหรือมีผลทดสอบแยกชุด
- เปรียบเทียบ 4 สูตรด้วย chronological validation ช่วง 30% และแยก final holdout 20% เลือกสูตรด้วย Log loss แล้วแสดงจำนวนถูกจริงของเลข 2 ตัวและ 6 ตัว
- แสดงผลทดสอบเลข 2 ตัว Top 10 แยกจาก 2 ชุดหลัก Top 10 ของเลข 6 ตัวใช้ผลคูณน้ำหนักรายหลักภายใต้สมมติฐานอิสระ
- รางวัลที่หนึ่งมีระบบเปรียบเทียบ 9 วิธีแยกจากเลข 2 ตัว เลือกด้วย Log loss รายหลักเฉลี่ยจากช่วง 30% แล้วตรึงสูตรก่อนทดสอบ 20% สุดท้าย เทียบสูตรที่เลือกกับสูตรเดิมและฐานโอกาสเท่ากันบนงวดชุดเดียวกัน แสดงถูกครบชุดหลัก ถูกครบใน Top 10 และถูกเลขตรงตำแหน่งแยกกัน
- ใช้ Web Worker คำนวณเพื่อไม่บล็อกหน้าจอ ใช้งานบนมือถือและคีย์บอร์ดได้
- เพิ่มหมวด “สูตรเลขเด่นทดลอง” แยกจากแบบจำลองเดิม: (เลขท้าย 2 ตัว + สามหลักท้ายรางวัลที่หนึ่ง) mod 10, (หลักร้อย × หลักสิบรางวัลที่หนึ่ง) mod 10 และ (วันที่งวดเป้าหมาย + เลขท้าย 2 ตัว + เลขคงที่ 0–99) mod 10 ให้เลขเด่นหนึ่งหลัก ไม่ได้แปลงเป็นเลข 2 หรือ 6 ตัวเอง
- สูตรวันที่ให้ระบุวันเป้าหมายจริง ไม่เดาวันจากตาราง 1/16 และเลขคงที่เริ่มต้น 0 เปลี่ยนได้ ผลย้อนหลังใช้ช่วงปีเดียวกันจนถึงงวดก่อนหน้าที่ระบุ นับว่าเลขเด่นอยู่ในหลักสิบหรือหลักหน่วยของเลขท้าย 2 ตัวหรือไม่ ไม่ใช่อัตราถูก 2 ตัวตรงหรือผลจาก holdout แยก

## แหล่งข้อมูลและข้อจำกัด

GLO: https://gdcatalog.glo.or.th/dataset/dataset_c4-9_01

GLO API ที่ทดสอบ: POST https://www.glo.or.th/api/lottery/getLatestLottery และ POST https://www.glo.or.th/api/lottery/getLotteryResultByPage พร้อม JSON {"page":1} คลังสาธารณะ ณ วันที่ดึงมี 397 งวด ข้อมูลก่อนคลัง GLO ใช้ CSV ของ https://github.com/zugetor/Machine-Learning-for-thai-Lottery (99 งวด) และให้ GLO สำคัญกว่าเมื่อวันที่ตรงกัน

อัปเดตคลังทั้งชุดใหม่ด้วย `python scripts/fetch-history.py` (Python standard library) โดยต้องเชื่อมต่ออินเทอร์เน็ต สคริปต์เก็บแหล่งที่มาและตรวจข้อมูลก่อนเขียน ไม่สร้างข้อมูลจำลอง ความครอบคลุมที่แสดงหมายถึงข้อมูลที่มี ไม่รับรองว่าไม่มีงวดตกหล่น แหล่งเสริมไม่ได้ยืนยันรายงวดกับเอกสาร GLO ทั้งหมด

คำว่า “วิเคราะห์” หมายถึงแบบจำลองทางสถิติ ไม่ใช้ LLM หรือสุ่มเลข ไม่มีสูตรที่พิสูจน์ว่าแม่นที่สุดทุกงวด การเลือกที่ทำได้ดีในอดีตไม่รับรองผลในอนาคต น้ำหนักแบบจำลองไม่ใช่โอกาสถูกจริง

สูตรรางวัลที่หนึ่งทั้ง 9 วิธีถูกกำหนดก่อนทดสอบ: ฐานเท่าเทียม, ความถี่รายหลักปรับเรียบ 1/10, งวดใหม่ครึ่งชีวิต 24/48 งวด (ปรับเรียบ 5), ความสัมพันธ์งวดก่อนน้ำหนัก 0.1/1 (ปรับเรียบ 5), สูตรเดิมปรับเรียบ 1 พร้อมน้ำหนักความสัมพันธ์ 0.25, และสูตรผสมความถี่ปรับเรียบ 10 สัดส่วน 50% + งวดใหม่ 48 งวด 25% + ความสัมพันธ์ 0.1 อีก 25% การทดสอบใช้เฉพาะประวัติก่อนงวดเป้าหมายและไม่เปลี่ยนสูตรตามผล holdout

หากฐานโอกาสเท่ากันชนะช่วงเปรียบเทียบ ทุกเลข 6 ตัวมีน้ำหนักเท่ากัน เว็บจะแสดงว่ายังจัดอันดับเลขเด่นไม่ได้ ไม่แสดงชุดหลักหรือ Top 10 ที่เกิดจากการเรียงเลขน้อยก่อน ผู้ใช้กดดู Top 10 ของสูตรสถิติที่ดีที่สุดในช่วงเปรียบเทียบเป็นผลทดลองได้ พร้อมดูผล holdout ของสูตรนั้นแยกจากสูตรที่ชนะ เกณฑ์เลือกสูตรทดลองไม่ใช้ข้อมูล holdout ส่วนการนับถูกของฐานเท่าเทียมในตารางเปรียบเทียบยังใช้กติกาตายตัว 000000 / 000000–000009 เพื่อให้ทำซ้ำได้ และระบุไว้ชัดว่าเป็นกติกาทดสอบ ค่า Log loss รายหลักของฐานเท่าเทียมคือ ln(10) ผลถูกตรงตำแหน่งไม่ใช่อัตราถูกครบ 6 ตัว และผลทดสอบหลักร้อยงวดยังไม่พิสูจน์ความได้เปรียบในงวดหน้า

เว็บไม่ซื้อสลาก ไม่ส่งข้อมูลให้บริการ AI และไม่มีค่า API ของ AI ใช้แหล่ง GLO สาธารณะที่ระบุ Open Data / non-commercial; ไม่รับรองว่า API จะเปิดหรือคงรูปแบบนี้ตลอดไป ค่าโฮสติ้งเป็นเรื่องแยกต่างหากหากนำไปออนไลน์
