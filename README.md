# Lucky Pixel

เว็บสถิติหวยส่วนตัว ภาษาไทย สไตล์ Pixel Art เปิดผ่านเบราว์เซอร์ ไม่ต้องสมัครสมาชิกหรือใช้ API key

## เปิดใช้งาน

ต้องมี Node.js 20.19+ หรือ 22.12+ และ npm

```powershell
npm install
npm run dev
```

เปิด http://127.0.0.1:5173 เซิร์ฟเวอร์ผูกกับเครื่องนี้เท่านั้น ไม่มีรหัสผ่านเพราะใช้ส่วนตัว

```powershell
npm run build
npm start
npm test
```

## ฟีเจอร์

- ตาราง 00–99 ตามรางวัลเลขท้าย 2 ตัวจริง เลือก 5 / 10 / 20 ปี สีเข้ม = ออกบ่อย แตะดูทุกวันที่เคยออก
- ข้อมูลจริง 496 งวดในคลังตั้งต้น (2549–2569) ระบุแหล่งรายงวด เก็บเลขศูนย์นำหน้า และดาวน์โหลด CSV ได้
- อัปเดต GLO อัตโนมัติทุก 2 นาทีขณะเซิร์ฟเวอร์เปิด เก็บแคชใน data/cache.json และดึงงวดที่ขาดหลังปิดเครื่องกลับมา หากเชื่อมต่อไม่ได้ยังใช้ข้อมูลเดิมได้พร้อมข้อความสถานะ
- กรอกผลและวันที่งวดก่อน คำนวณ 2 ตัว 2 ชุด และ 6 ตัว 1 ชุดแบบไม่มีการสุ่ม เปลี่ยนอินพุตหรือช่วงปีแล้วล้างผลเก่าป้องกันความสับสน
- เปรียบเทียบ 4 สูตรด้วย chronological validation ช่วง 30% และแยก final holdout 20% เลือกสูตรด้วย Log loss แล้วแสดงจำนวนถูกจริงของเลข 2 ตัวและ 6 ตัว
- ใช้ Web Worker คำนวณเพื่อไม่บล็อกหน้าจอ ใช้งานบนมือถือและคีย์บอร์ดได้

## แหล่งข้อมูลและข้อจำกัด

GLO: https://gdcatalog.glo.or.th/dataset/dataset_c4-9_01

GLO API ที่ทดสอบ: POST https://www.glo.or.th/api/lottery/getLatestLottery และ POST https://www.glo.or.th/api/lottery/getLotteryResultByPage พร้อม JSON {"page":1} คลังสาธารณะ ณ วันที่ดึงมี 397 งวด ข้อมูลก่อนคลัง GLO ใช้ CSV ของ https://github.com/zugetor/Machine-Learning-for-thai-Lottery (99 งวด) และให้ GLO สำคัญกว่าเมื่อวันที่ตรงกัน

อัปเดตคลังทั้งชุดใหม่ด้วย `python scripts/fetch-history.py` (Python standard library) โดยต้องเชื่อมต่ออินเทอร์เน็ต สคริปต์เก็บแหล่งที่มาและตรวจข้อมูลก่อนเขียน ไม่สร้างข้อมูลจำลอง ความครอบคลุมที่แสดงหมายถึงข้อมูลที่มี ไม่รับรองว่าไม่มีงวดตกหล่น แหล่งเสริมไม่ได้ยืนยันรายงวดกับเอกสาร GLO ทั้งหมด

คำว่า “วิเคราะห์” หมายถึงแบบจำลองทางสถิติ ไม่ใช้ LLM หรือสุ่มเลข ไม่มีสูตรที่พิสูจน์ว่าแม่นที่สุดทุกงวด การเลือกที่ทำได้ดีในอดีตไม่รับรองผลในอนาคต น้ำหนักแบบจำลองไม่ใช่โอกาสถูกจริง สูตร 6 หลักใช้ความถี่รายหลักบวกน้ำหนักความสัมพันธ์รายหลัก 0.25 และรายงาน exact-match holdout แยกต่างหาก

เว็บไม่ซื้อสลาก ไม่ส่งข้อมูลให้บริการ AI และไม่มีค่า API ของ AI ใช้แหล่ง GLO สาธารณะที่ระบุ Open Data / non-commercial; ไม่รับรองว่า API จะเปิดหรือคงรูปแบบนี้ตลอดไป ค่าโฮสติ้งเป็นเรื่องแยกต่างหากหากนำไปออนไลน์
